# Resume Service

Сервис для создания, хранения и адаптации резюме под конкретные вакансии.

Основная идея проекта — собрать в одном месте информацию о пользователе, его опыте, образовании, навыках и проектах, после чего использовать эти данные для генерации и улучшения резюме.

В дальнейшем сервис должен позволять анализировать GitHub-профиль пользователя, автоматически дополнять карьерный профиль, адаптировать резюме под описание вакансии и экспортировать результат в PDF.

## Основные возможности

Планируемый пользовательский сценарий:

1. Регистрация и авторизация пользователя.
2. Создание карьерного профиля.
3. Добавление опыта работы, образования, навыков и проектов.
4. Создание одного или нескольких резюме на основе профиля.
5. Подключение GitHub и анализ репозиториев пользователя.
6. Генерация и улучшение описаний опыта и проектов с помощью AI.
7. Анализ вакансии.
8. Адаптация существующего резюме под конкретную вакансию.
9. Экспорт готового резюме в PDF.
10. Хранение нескольких версий резюме.
